# TurtleBot3 AI Obstacle Avoidance

## 1. 概要

Physical AI応用1講座の最終課題として、ROS 2とGazeboを用い、TurtleBot3の障害物回避タスクを実装しました。

LiDARで前方・左右の障害物までの距離を取得し、距離重み付きk-NNにより旋回方向（LEFT / RIGHT）を推論します。

## 2. 使用技術

- ROS 2 Humble
- Gazebo Classic
- TurtleBot3 Burger
- Python 3 / rclpy
- 距離重み付きk-NN（k=3）

## 3. AIの実装

左右の障害物距離を特徴量とし、人手で生成した30件の教師データから近傍3件を検索します。距離に応じた重み付き投票で旋回方向を決定します。

教師データはルールに基づく合成データであり、実走行から学習したものではありません。

## 4. 実行手順

ROS 2 Humble、TurtleBot3 Gazeboパッケージが導入された環境を使用します。

1. Gazeboの `empty_world.launch.py` を起動します。
2. `obstacle.sdf` をワールド座標 `(1.5, 0.0, 0.3)` に配置します。
3. `ai_avoid_robot_long.py` を実行します。

録画用スクリプト `record_long.sh` では、ワールドのリセットと待機の後にAI制御を実行します。

## 5. 実験結果

LiDARによる障害物検知、k-NNのRIGHT推論、右旋回、走行継続を確認しました。65秒の時間制限による正常終了を確認しています。

## 6. 制約と今後の課題

- 今回は単一障害物を対象とした簡易実験です。
- k-NNは左右距離のみを入力とするため、経路計画や自己位置の記憶は行いません。
- 左右が同距離の場合、学習例と同点時の処理が出力に影響します。
- 今後は走行経路の記録や複数障害物への対応を検討します。
